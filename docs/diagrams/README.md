# Diagram assets

README displays static SVG without external requests. SVG text, shapes and arrows remain editable. Mermaid sources preserve the semantic model.

To export, download an HTML file and open it in a browser. The toolbar provides PNG, clipboard and PDF export. HTML export uses Google Fonts and the pinned html2canvas/jsPDF CDN scripts from the upstream template; the SVG diagrams themselves need no network access.

Design rules and HTML template: [Cocoon AI / Architecture Diagram Generator](https://github.com/Cocoon-AI/architecture-diagram-generator), MIT. License retained alongside these files and inside each HTML file. Typography is enlarged for README readability. Layouts and system content are project-specific.
